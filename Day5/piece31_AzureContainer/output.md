# Azure Container Apps — Day 5 piece 31

## Azure CLI Commands

### Create Resource Group

```bash
az group create -n thinkschool-rg -l "Southeast Asia"
```

### Create Container Apps Environment

```bash
az containerapp env create -n thinkschool-env -g thinkschool-rg -l "Southeast Asia"
```

### Show Container Apps Environment (JSON)

```bash
az containerapp env show -n cae-nb3bgcnwnlpwe -g rg-quotesapi-dev -o json
```

# What Would Break This?

- Invalid Azure region name
- Missing Azure login (`az login`)
- Missing `containerapp` extension
- Subscription quota limits
- Network or permission issues during deployment
